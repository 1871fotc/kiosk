# Toowong Cemetery Honour Board Information Kiosk

The Toowong Cemetery Remembrance Pavilion and Honour Board project is planning to create a place to remember all the people commemorated in Toowong Cemetery that served their country in military conflicts.

This work starts with the 3,500+ Australians who served and may extend by another 3,500+ people who served other countries. 

This code and content will generate an offline website that will power an information kiosk within the Remembrance Pavilion. 

The site is built with [Zensical](https://zensical.org) which has been configured as a lockdown information kiosk rather then the usual websites it creates.
 
## Development

- Go to you development environment (e.g. Visual Studio)
- Open your project folder
- [Install Zensical](https://zensical.org/docs/get-started/#install-with-pip) using Termnial

```
python3 -m venv .venv
source .venv/bin/activate
pip install zensical
```
